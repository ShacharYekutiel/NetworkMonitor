# SegmentedControl

A row of mutually exclusive options: chart range (1 hour · 24 hours · 7 days · 30 days), ports view (Front panel · Port list), theme (System · Light · Dark), SMTP security.

**Consumer provides:** options and the selected value. Two to five short labels; anything longer is a Select.

- Selected segment is `accent` with `on-accent` text; others `surface` with `ink-muted`; outline `border-strong`.
