# Tabs

Underlined tabs that switch views within one page (Device: Ports · Sensors; Discovery: Scan · Scans · Saved profiles; Notifications: Channels · Rules). The active tab is in the URL (`?tab=`).

**Consumer provides:** tabs with label, optional icon and count; the selected key.

- Active: `ink`, 600, 2px `accent` underline. Inactive: `ink-muted`. Counts are `.nm-chip`.
