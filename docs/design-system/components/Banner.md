# Banner

Inline messages: info (active maintenance, scope notes), success (best match on Find, test sent), warning and error (form or load errors). The global maintenance banner spans the top of the content area.

**Consumer provides:** tone, icon, text, optional end link or action.

- Ground is the tone's soft token (`accent-soft`, `status-*-soft`), text `ink`, icon in the tone colour. `radius-lg`; the global variant is square and full-width.
- One banner per concern; never stack more than two.
